# 1030 nm NALM 九字腔光纤激光器锁模仿真方案

## 仿真目标
- 建立基于非线性偏振旋转耦合的非对称环形镜（NALM）的九字腔光纤激光器时域仿真模型。
- 使用四阶龙格-库塔汇景（RK4IP）算法求解非线性薛定谔方程（NLSE），模拟腔内脉冲在各段光纤中的传播。
- 使用四阶龙格-库塔算法求解速率方程，描述Yb3+增益光纤的反转粒子数动态及增益饱和过程。
- 分析泵浦功率、腔内损耗、总色散量、增益光纤位置与长度、平均输出功率等参数对锁模稳态以及相位噪声、强度噪声的影响。

## 模型假设与参数
- 工作波长：1030 nm。
- 激光器结构：NALM + 9 字腔；腔内包含增益光纤、无源光纤、耦合器、色散补偿光栅（CFBG）等元件。
- 增益介质：YB401-PM，假设小信号吸收 600 dB/m @ 975 nm，采用两能级速率方程模型；寿命与截面采用典型Yb掺杂参数。
- CFBG 提供二阶色散 D = 0.2 ps/nm，带宽（FWHM）=16 nm，视为频域滤波器实现。
- 泵浦功率扫描范围：0–1 W。
- 考虑自相位调制（SPM）、群速度色散（GVD）、腔内损耗、耦合器分束比等效应。

## 数值算法
### NLSE（场演化）
- 采用 RK4IP（Fourier split-step RK4）方法分段积分每个光纤段。
- 在线性算符中包含色散、损耗、滤波与平均增益；非线性算符包含SPM和通过速率方程反馈的瞬时增益调制。
- 时间域离散：选取覆盖脉冲全宽的窗口，采用 $2^N$ 点 FFT 便于频域处理。

### 速率方程（增益演化）
- 对增益纤维内的反转粒子数 $N_2$ 使用四阶 RK 积分。
- 输入为泵浦功率（沿长度衰减可选指数模型）与信号平均功率；输出为局部小信号增益系数 $g(z)$ 与饱和能量。
- 将求得的增益分布映射到 NLSE 的线性算符中，随回程更新。

## 噪声分析
- 锁模稳态判据：脉冲能量、谱宽与时宽收敛，输出功率波动 < 设定阈值。
- 强度噪声（RIN）：计算输出脉冲包络强度序列的时间域波动，并对其进行 FFT 得到功率谱密度。
- 相位噪声：提取输出光场相位中心随回程的波动，计算对应 PSD。

## 扫描流程
1. 初始化时间网格、频率网格与腔段参数；给定初始噪声脉冲或高斯猜测。
2. 对每个参数组合（泵浦功率、损耗、色散等）迭代多个腔周回：
   - 更新增益纤维速率方程，获得当前 round-trip 的增益系数。
   - 依次通过九字腔的各段光纤/元件传播脉冲，使用 RK4IP 完成步进。
   - 在输出端记录功率、脉冲形状、相位。
3. 判断是否达到锁模稳态；若达到，统计平均输出功率、脉冲宽度等。
4. 对稳态序列进行噪声分析，形成 RIN、相位噪声随参数的曲线。

## 实现文件
- `simulations/nalm_simulation.py`：包含模型实现、RK4IP 与速率方程求解器，以及参数扫描与噪声分析工具函数。
- 支持命令行参数或在脚本中定义扫描配置，输出结果保存为 NumPy/CSV 与可选图像。

## 后续扩展建议
- 引入双向传播的泵浦耗尽模型以精细描述NALM中的非线性耦合。
- 结合实验测得的增益截面与寿命参数以提高定量准确性。
- 加入偏振态演化（如使用 Manakov 方程）以模拟 PM 光纤内的双折射效应。
- 与实验数据对比，调优损耗与器件参数。
